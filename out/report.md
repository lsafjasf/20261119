# Opus 丢包隐藏（PLC）仿真实验报告

## 1. 实验设置

- **测试信号**：共振峰合成元音 /a/ /i/ /u/ 与带通噪声摩擦音 /s/ /ʃ/ 各 350 ms 拼接（5 ms 交叉淡化），16 kHz 单声道，共 1.83 s / 91 帧（`out/source.wav`）。
- **编解码**：真实 libopus（系统 `libopus.so.0`，ctypes 调用），20 ms 帧（320 样本），24 kbps CBR，VOIP 模式，每包 60 字节。
- **参考**：同一包流无丢包解码（`out/reference_lossless_decode.wav`）。**参考仅用于误差计算，绝不参与缺口填充**；所有隐藏策略严格因果，只能看到此前已输出（解码或已隐藏）的样本。
- **丢包模式**（帧号）：
  - 孤立丢包：`iso_vowel_a`(8)、`iso_fric_s`(26)、`iso_vowel_i`(44)
  - 连续三包：`burst3_vowel_i`(45-47)、`burst3_vowel_u`(74-76)、`burst3_fric_sh`(60-62)
- **长度一致性**：每种策略输出总样本数与参考完全一致（仿真中逐样本断言），丢包帧由策略填充、不少不多。
- **解码器状态**：丢包帧调用 `opus_decode(NULL)` 推进解码器状态（标准做法），但除 `opus_builtin` 外均丢弃其输出，改用各策略自己的填充。

## 2. 三种隐藏策略（+Opus 内置 PLC 对照）

| 策略 | 填充方式 | 衔接处理 |
|---|---|---|
| `silence` | 缺口填零（朴素基线） | 无（硬接缝） |
| `repeat` | 重复最后一个完好帧，连丢时逐帧 ×0.95 衰减 | 无（硬接缝） |
| `lpc_pred` | LPC-16 谱包络 + 基音周期残差回放激励外推（类 SILK PLC），浊音强度由最近两个基音周期相关系数估计，噪声增益 = 残差能量×(1−浊音度)，能量与近 20 ms 历史匹配 | 入口天然连续（滤波器状态延续）；出口 5 ms 重同步叠接（NetEq 式 merge） |
| `opus_builtin`（对照） | libopus 解码器内置 PLC 输出 | 出口 5 ms 重同步叠接 |

## 3. 指标定义

- **RMSE / SNR(dB)**：隐藏段内与参考的逐样本误差（相位敏感）。
- **LSD(dB)**：对数谱距离，10 ms 窗 5 ms 移，谱包络差异（相位不敏感）。
- **click_step**：接缝样本处一阶差分 |x[b]−x[b−1]|（取入/出口较大者），无参考咔哒声检测。
- **click_hf(dBFS)**：接缝 ±4 ms 内 4–8 kHz 带通能量（绝对值，可跨策略比较）。
- **hf_excess(dB)**：同窗口高频能量相对参考的超出量（元音处参考高频≈0，数值会放大，仅供方向性参考）。

## 5. 分析

### 恢复段误差
- **元音**：`lpc_pred` 明显最优（SNR 14–20 dB，三连包后仍 15–17 dB），因为 LPC+基音外推同时保住了谱包络和谐波相位结构；`repeat` 硬重复导致基音相位错位，波形域误差比信号本身还大（SNR 为负），且连丢时误差累积（LSD 8→17 dB）；`silence` 按定义 SNR≈0 dB，LSD 超 110 dB（谱完全缺失）。`opus_builtin` 孤立丢包表现好（9–14 dB），但连丢时其内部衰减使输出快速静音化，SNR 跌至 ≈0 dB。
- **摩擦音**：噪声不可预测，任何填充的波形误差都 ≥ 信号能量（SNR≤0）。此时 `silence` 的 RMSE 反而最小（零填充误差=信号能量，非零填充误差≈√2 倍），但 LSD 暴露了其代价（150 dB，频谱完全塌陷）；`repeat`/`lpc_pred`/`opus_builtin` 的 LSD 都在 7–9 dB，听感上保留了噪声的音色。

### 衔接处咔哒声
- `silence`/`repeat` 为硬接缝：元音处 click_step 0.23–0.67（接近信号幅度），接缝高频能量 −12 ~ −20 dBFS，可闻"咔哒"明显；`repeat` 在每个 20 ms 重复边界都有接缝（频谱图上呈周期性竖条纹）。
- `lpc_pred` 入口由滤波器状态自然延续（step 低至 0.03–0.08），出口 5 ms 重同步叠接，残留咔哒能量低一个数量级；连丢 3 包后出口 step 仍 ≤0.23。
- `opus_builtin` 接缝最平滑（三连包 step≈0.03，高频 −38 dBFS），代价是恢复段被衰减。
- 摩擦音段所有策略的接缝指标都小：噪声本身的高频把接缝不连续掩蔽了。

### 频谱差
- `silence` 在缺口处谱完全缺失（LSD 110–154 dB），听感为"洞"。
- `repeat` 谱包络保持尚可（LSD 7–9 dB），但连丢时谱僵化（同一帧重复，LSD 升至 16–18 dB），听感"机器嗡鸣"。
- `lpc_pred` 元音 LSD 7–12 dB，谐波结构延续（见 `out/spectrogram_burst3_vowel_u.png`：缺口内谐波横条纹连续）；摩擦音段与 repeat 相当。

### 主观听感（基于客观指标与 PLC 文献的预测，请用 WAV 验证）
本环境无法实际放音，以下为由上述指标支撑的预期听感排序，建议用 `out/*.wav` 自行验证：
1. **元音孤立丢包**：`lpc_pred` 几乎不可察觉 > `opus_builtin`（轻微音调下坠）> `repeat`（可闻"叭"声+音调突变）> `silence`（明显断裂+咔哒）。
2. **元音三连包**：`lpc_pred` 可闻但自然（元音延续、略单调）> `opus_builtin`（声音淡出再淡入，无咔哒但"吞字"）> `repeat`（嗡鸣+接缝咔哒）> `silence`（60 ms 空洞+两次咔哒）。
3. **摩擦音**：三者差距缩小，`repeat`/`lpc_pred` 听感接近（噪声延续），`silence` 仍有可闻"缺口"，但在噪声掩蔽下比元音段轻微。

## 6. 输出文件

- `out/source.wav`：原始合成信号；`out/reference_lossless_decode.wav`：无丢包参考解码
- `out/{模式}__{策略}.wav`：每个丢包模式 × 策略的修复结果（18 + 6 个对照文件，样本数全部一致）
- `out/metrics.csv`：全部量化指标
- `out/spectrogram_*.png` / `out/waveform_*.png`：三个代表案例的频谱图与波形对比（红区为隐藏段）

## 7. 复现

```bash
python3 plc_sim/run_sim.py     # 仿真 + 指标 + WAV
python3 plc_sim/make_plots.py  # 图
```
依赖：numpy、scipy、matplotlib、系统 libopus.so.0。
